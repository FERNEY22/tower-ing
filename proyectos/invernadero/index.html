¿Qué es? Prototipo que convierte las lecturas de los sensores de un invernadero de rosas en un reporte en lenguaje natural, escrito y hablado, mediante la API Text-to-Speech del navegador.

  1. Pulse Leer datos: simula la lectura de la red de sensores y genera valores aleatorios de temperatura, humedad y pH. Cada clic es una nueva lectura.
  2. Revise el reporte escrito con el estado del invernadero.
  3. Pulse Reporte para escucharlo en voz.
  4. Cambie el idioma a English para obtener el reporte en inglés.
