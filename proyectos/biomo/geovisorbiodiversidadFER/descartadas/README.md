# Capas descartadas

`Erosion por aluminio.geojson` se retiró del visor el 2026-09-17 porque es una copia byte a byte de `Erosion climatica.geojson` (misma geometría y mismos atributos, `UCS_CP = "Erosión climática"`, `CLASE = III`): no existe una capa real de erosión por aluminio, es un artefacto de la exportación desde QGIS. Se conserva aquí solo como evidencia de trazabilidad; no debe volver a embeberse en `index.html`.
